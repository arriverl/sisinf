# 课程论文使用说明

## 文件

| 文件 | 说明 |
|------|------|
| `docs/课程论文_SIS无穷范数求解.tex` | 暨南大学本科生课程论文 LaTeX 源文件（主文档） |
| 本说明 | 编译与填写指引 |

## 填写封面信息

用编辑器打开 `.tex`，修改以下宏（约第 28–35 行）：

```latex
\newcommand{\college}{信息科学技术学院}
\newcommand{\major}{信息安全}
\newcommand{\studentname}{张三}
\newcommand{\studentid}{2023123456}
\newcommand{\coursename}{格密码学导论}
\newcommand{\advisor}{李老师}
\newcommand{\submitdate}{2026年6月3日}
```

## 编译

需安装 TeX Live（含 `ctex`）并支持 **XeLaTeX**：

```bash
cd docs
xelatex 课程论文_SIS无穷范数求解.tex
xelatex 课程论文_SIS无穷范数求解.tex   # 第二遍生成目录
```

Windows 也可用 TeXstudio / Overleaf，编译器选 **XeLaTeX**。

## 论文章节对应模板

| 模板要求 | 论文章节 |
|----------|----------|
| 摘要、关键词 | 摘要页 |
| 1. 引言 | `\section{引言}` |
| 2. 原理或方案设计 | `\section{原理或方案设计}` |
| 3. 程序实现或算法分析 | `\section{程序实现或算法分析}` |
| 4. 总结 | `\section{总结}` |
| 参考文献 | `\begin{thebibliography}` |
| 附录 | `\appendix` |
